# Laya 공시 분류 미세조정 (2026-09-23)

## 3줄 요약
- **T1(공시 종류, 보고서 이름을 가린 본문만 읽기)은 통과했다.** 인코더 윗부분 6층을 미세조정한 Laya가 시험 구간(2025~2026)에서 매크로 F1 0.846으로 키워드 규칙(0.734)보다 11.2%p 높았고, 확신도도 잘 맞았다(ECE 0.021, 확신 0.99 이상 552건 중 99.3% 정답). 그냥 쓰면(zero-shot) 0.312였다. **미세조정하면 한국어 공시 본문을 읽을 수 있다**는 관문은 넘었다.
- **T2(자사주 취득 목적)는 실패했다.** 매크로 F1 0.28로 규칙(0.13)보다는 높지만 확신도가 안 맞고(ECE 0.155, 기준 0.10), 정작 중요한 **"소각" 111건 중 3건만 맞혔다.** 학습 구간에는 소각이 8%뿐이었는데 시험 구간에는 27%로 늘었다(2025년 이후 소각 목적 자사주가 급증). 모델은 거의 전부를 "주가안정·주주가치"로 몰았다.
- **사전 판정 규칙(두 과제 모두 통과)에 따라 봇 편입은 비채택.** 다만 T1 결과는 "정형 자료 없는 공시를 읽는 과제"(T3)로 넓힐 근거가 된다. T2는 반 비율이 바뀌어도 버티는 학습(반 가중치 등)을 새로 설계해야 한다.


## 0. 사전 고정 설계 (결과를 보기 전에 적었다. 이후 바꾸지 않는다)

**왜 하나.** 09 실험에서 Laya를 그냥 쓰면(미세조정 없음) 한국어 사업보고서를 거의 못 읽었다. 공시에는 정형 자료나 보고서 이름이라는 "공짜 정답"이 수천 건 있어서, 미세조정하면 읽을 수 있게 되는지 정직하게 잴 수 있다.

**T1은 관문이다.** 공시 종류는 보고서 이름만 봐도 안다. 실용 가치는 "이름을 가려도 본문만으로 읽을 수 있나"다. 이걸 못 하면 정형 자료가 없는 공시(T3 후보)로 넓힐 근거가 없다.

| 항목 | 고정한 값 |
|---|---|
| 자료 | OpenDART 주요사항보고서(pblntf_ty=B) 2019-01 ~ 2026-09, 상장사만, `[기재정정]`·유무상증자 제외 |
| T1 질문 | 본문을 읽고 {유상증자, 전환사채, 신주인수권부사채, 무상증자, 자기주식취득, 자기주식처분, 기타} 중 하나 |
| T1 정답 | 보고서 이름 괄호 안(예: `주요사항보고서(전환사채권발행결정)`). 그 밖의 종류(합병, 양수도, 감자, 신탁계약 등)는 `기타` |
| T1 누수 차단 | 입력에서 보고서 이름과 결정 이름(예: "유상증자결정", "전환사채권 발행결정", 띄어쓰기 변형 포함)을 모두 지운다. 표지(회사명·제출일·금융위원회 귀중)도 지운다 |
| T2 질문 | 자기주식취득결정 본문을 읽고 목적이 {소각, 주가안정·주주가치(보유), 임직원 보상, 기타} 중 무엇인지 |
| T2 정답 | 본문 표의 `취득목적` 칸을 규칙으로 읽는다. 순서: "소각" 있으면 소각 → 임직원·성과보상·상여·우리사주·주식매수선택권·스톡옵션이면 임직원 보상 → 주가안정·주주가치·주주환원·가치제고·주주이익이면 주가안정·주주가치 → 나머지 기타. 목적 칸을 못 찾으면 표본에서 뺀다 |
| T2 누수 차단 | 입력에서 `취득목적` 칸의 내용을 지운다. 다른 칸(예: 기타 투자판단 참고사항)에 목적이 다시 적혀 있으면 그대로 둔다 — 실제 공시를 읽는 상황과 같다 |
| 표본 목표 | T1 반별 200~320건(자기주식취득은 T2 표본 전체를 같이 씀), T2는 자기주식취득결정 전부(약 1,000건 예상). 모자라면 있는 만큼 |
| 입력 | 정리한 본문 앞부분, 토큰 512개(질문·보기 포함) |
| 분할 (시기) | 학습 접수일 ≤ 2023-12-31, 검증 2024, **시험 2025-01 ~ 2026-09**. 시험 구간은 마지막에 한 번만 본다 |
| 방법 | (a) zero-shot Laya(비교용) (b) 인코더 고정 + Laya 판단 머리만 학습 (c) 인코더 윗부분 6층 + 머리 미세조정. 둘 다 교차엔트로피(로그 손실 — 엄격히 적절한 점수 규칙), 검증 구간으로 에폭 선택과 온도 보정 |
| 기준선 | 같은 입력(누수 차단 뒤 본문)에 거는 키워드 규칙. T1: 본문 특유 항목명("신주의 종류와 수", "사채의 종류", "신주인수권에 관한 사항", "1주당 신주배정 주식수", "취득예정주식", "처분예정주식" 등). T2: 남은 본문에서 목적 문구 키워드(정답 규칙과 같은 순서) |
| 측정 | 정확도, 매크로 F1, 혼동행렬, ECE(15구간), 확신 구간별 정확도, 확신 ≥ 0.9 커버리지와 그 정확도, 학습 시간, 추론 지연 |
| 판정 | 시험 구간에서 (1) 키워드 기준선보다 매크로 F1 +5%p 이상, **또는** 기준선과 비슷하면서(±2%p) 규칙이 못 잡는 경우를 잡는 증거 **그리고** (2) ECE ≤ 0.10. 두 과제 모두 기준을 넘으면 "봇 편입 설계로 진행 가치 있음", 아니면 비채택 |

**미리 밝히는 한계.** 사전학습 자료에 공시가 들어 있었을 수 있다(미래 정보). 다만 "이 공시가 무슨 종류인가"는 "주가가 오를까"보다 이 위험이 작다. 정답이 규칙에서 나오므로 규칙이 틀린 만큼 정답도 틀린다.

## 4. 판정

**비채택**(사전 규칙: 두 과제 모두 통과해야 봇 편입 설계). 

얻은 것:
- 미세조정한 Laya는 이름을 가린 한국어 공시 본문으로 공시 종류를 94.7% 맞히고, 확신 0.99 이상이면 99.3% 맞는다. 확신도로 "사람에게 넘길 것"을 가를 수 있다.
- 과제를 넓힐 때의 위험도 확인했다. 반 비율이 시기에 따라 크게 바뀌는 과제(자사주 소각 급증)에서는 과거로 학습한 모델이 새 흐름을 놓친다.

다시 볼 조건:
- T2는 반 가중치나 균형 표본으로 다시 학습하고, 목적 칸 대신 "기타 투자판단 참고사항"까지 넣어 새로 설계한다.
- 받지 못한 646건을 받아 T1 반 비율을 맞춘다.
