# 트레이딩 봇 요구사항 정의서 (초안 v0.1, 2026-09-21)

## 3줄 요약
- **목적**: 검증된 재무·위험 지표로 월 1회 종목을 교체하는 자동 매매 봇. 목표는 코스피보다 높은 수익이 아니라 **비슷한 수익을 절반의 손실폭으로** 얻는 것이다.
- **근거**: [03 검증](03-지표-영향-검증/README.md)에서 유효했던 지표만 쓴다. 수급 추종, 거래량 급증 추격, 호재 공시 추격은 손실이 확인되어 금지한다.
- **비용**: 언어모델과 GPU를 쓰지 않는다. 운영비는 집 PC 전기요금뿐이다.

  end

  end
  subgraph 매일
    W1[잔고·손실한도 점검] --> W2[텔레그램 알림]
  end
  O3 --> W1

## 1. 검증 근거와 설계 결정
| 검증 결과 | 설계 결정 |
|---|---|
| 영업이익 성장, 자기자본이익률, 이익/시총, 매출/시총이 유효 (t값 2.0~4.4) | 종목 선정 점수에 사용 |
| 고변동성·고회전율 종목은 월 -1.9% (t값 -3.0) | 점수에서 감점 |
| 외국인·기관 순매수 무효, 거래량 급증 추격 연 -21% | 사용 금지 |
| 호재 공시 다음날 매수 승률 39% ([02 검증](02-공시-이벤트-스터디/README.md)) | 공시 기반 매수 금지 |
| 외부 요인은 다음 달을 예측 못 함, 시가에 선반영 | 예측에 쓰지 않음 |
| 코스피가 10개월 평균 아래면 다음 달 평균 -0.45% | 전량 현금 전환 스위치로만 사용 |
| 분기 갱신 시 효과 +1.24%에서 +1.63%로 상승, 공개 후 30일 이내 정보는 +2.18% | 분기 재무와 실제 공시 일시 사용, 실적 공개일 기준 교체 |
| 종합 전략 연 18.8%, 손실폭 -39% (폐지 종목 포함). 하락장 현금 전환 적용 시 19.1%, -15% | **현금 전환을 포함한 형태만** 기본 전략으로 채택. F4는 선택이 아닌 필수 |

## 2. 기능 요구사항
| 번호 | 기능 | 내용 | 우선순위 |
|---|---|---|---|
| F1 | 시세 수집 | 전 종목 일봉(시가·종가·거래량)을 매일 장 마감 후 저장 | 필수 |
| F2 | 재무 수집 | 전자공시 API로 분기 재무와 잠정실적 공시를 받아 **실제 접수 일시**와 함께 저장. 모든 지표는 그 시점 이후에만 사용 | 필수 |
| F2-1 | 실적 공개일 기준 교체 | 월말 일괄 교체에 더해, 보유·후보 종목의 실적이 공개되면 5거래일 안에 점수를 다시 계산해 교체 | 필수 |
| F3 | 종목 선정 | 대상 필터 후 6개 지표 순위 합산, 상위 20개 선정 | 필수 |
| F4 | 추세 필터 | 월말 코스피가 10개월 평균 아래면 목표 비중을 0으로 | 필수 |
| F5 | 주문 실행 | 목표와 잔고의 차이만 주문. 매도 먼저, 지정가 분할, 미체결 재주문 | 필수 |
| F6 | 안전장치 | 일 손실 한도, 종목당 최대 비중, 주문 중복 방지, 수동 정지 | 필수 |
| F7 | 기록·대조 | 모든 판단·주문·체결을 저장하고 매일 계좌와 대조 | 필수 |
| F8 | 알림 | 주문, 오류, 일일 요약을 텔레그램으로 전송 | 필수 |
| F9 | 성과 보고 | 월별 수익을 코스피·백테스트 값과 비교 | 권장 |
| F10 | 모의·실전 전환 | 설정 하나로 전환, 코드 분기 없음 | 필수 |

## 3. 데이터와 API
| 용도 | 출처 | 비용 | 비고 |
|---|---|---|---|
| 주문·잔고·시세 | 한국투자증권 오픈API (REST, 웹소켓) | 무료 | 리눅스 가능, 모의계좌 제공. 모의계좌는 호출 한도가 낮음 |
| 재무제표 | 전자공시 오픈API | 무료 | 키 발급 필요 |
| 상장폐지 포함 과거 시세·시총 | 거래소 정보데이터시스템 | 무료 | 회원가입 필요. 재검증에 필수 |
| 투자자별 매매, 뉴스, 재무비율 | 한국투자증권 API에 있음 | 무료 | 검증 결과 무효라 v1에서는 수집만 |

## 4. 비기능 요구사항
| 항목 | 기준 |
|---|---|
| 실행 환경 | 집 PC, 파이썬 단일 프로세스, SQLite. GPU 불필요 |
| 장애 내성 | 봇이 꺼져도 계좌가 위험하지 않을 것. 재시작 시 잔고 조회로 상태 복구 |
| 재현성 | 같은 날짜 입력이면 같은 종목이 나올 것. 백테스트와 실전이 같은 선정 코드를 사용 |
| 보안 | API 키는 환경변수, 저장소에 올리지 않음 |
| 최소 자금 | 20종목 분산에 약 300만원. 미만이면 10종목과 주가 상한 필터 적용 |

## 5. 단계별 합격 기준
| 단계 | 기간 | 합격 기준 | 불합격 시 |
|---|---|---|---|
| 1. 재검증 | 완료 (2026-09-21) | 상장폐지 종목 포함 데이터로 연복리 10% 이상, 손실폭 -25% 이내. **결과: 하락장 현금 전환 포함 시 19.1% / -15%로 통과. 현금 전환 없이는 18.8% / -39%로 손실폭 기준 미달** | 전략 폐기 |
| 2. 모의투자 | 3개월 | 봇의 월 수익과 백테스트 값의 차이 월 1%p 이내, 주문 오류 0건 | 실행 로직 수정 |
| 3. 소액 실전 | 6개월 | 비용 차감 후 전 종목 동일 비중 기준 초과, 손실폭 -20% 이내 | 중단 |
| 4. 증액 | 이후 | 3단계 통과 시에만 | - |

## 6. 범위에서 제외
- 분·초 단위 매매, 공시·뉴스 기반 매매, 언어모델·Laya 분류기
- 타인 대상 신호 판매나 자금 운용 (투자자문·일임 규제 대상)

## 7. 결정이 필요한 사항
| 항목 | 선택지 | 제안 |
|---|---|---|
| 운용 자금 | 50만원 / 300만원 이상 | 50만원은 종목 분산이 안 됨. 모의투자 기간에 결정 |
| 종목 수 | 10 / 20 / 30 | 20. 검증상 10~50 모두 유효 |
| 대상 범위 | 소형주 포함 / 중대형주만 | 소형주 포함이 수익은 높지만 체결 오차와 상장폐지 위험이 큼. 1단계 재검증 후 결정 |
