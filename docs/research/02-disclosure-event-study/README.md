# 공시 유형별 주가 반응 검증 (2026-09-21)

## 질문
호재 공시가 나오면 정말 오르는가. 그리고 공시를 보고 사면 돈이 되는가.

## 방법
| 항목 | 내용 |
|---|---|
| 기간 | 2024-01-02 ~ 2026-08-20 |
| 대상 | 코스피·코스닥 상장사의 최초 공시 6,119건 (정정·자회사 공시 제외) |
| 공시 출처 | 금융감독원 전자공시 상세검색 |
| 주가 | 일봉 시가·종가 (수정주가) |
| 초과수익 | 같은 시장 종목들의 동일가중 평균 수익률을 차감 |
| 공시 반응 | 공시 전일 종가 → 공시 다음날 종가 |
| 매매 가정 | 공시 다음 거래일 시가에 매수, N일 뒤 종가에 매도, 왕복 비용 0.25% |

## 한계
- 일봉만 사용. 공시 시각을 몰라 장중 공시 직후 매수는 검증하지 못했다.
- 회사명으로 종목코드를 찾아 11%가 누락됐다. 상장폐지 종목이 빠져 결과가 실제보다 좋게 보일 수 있다.
- 시가 매수 가정은 소형주에서 체결 오차가 크고, 상한가 종목은 실제로 살 수 없다.
- 기간이 2년 8개월로 짧다. 유상증자는 제3자배정과 주주배정이 섞여 있다.
